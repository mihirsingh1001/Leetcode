> **Don't memorize solutions. Understand the pattern.**


## Complexity Matters

```java
// ❌ Works
O(n²)

// ✓ Better
O(n log n)

// ✓✓ Best when possible
O(n)
```

Every accepted solution is not necessarily a good solution.

**The goal is to understand the trade-offs.**
